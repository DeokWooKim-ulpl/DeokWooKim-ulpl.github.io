Planar waveguide modes analyzer: Prism coupler

Theory and Application

This tool implements a prism coupling analysis for determining thin film optical properties using waveguide mode excitation angles. The prism coupler technique is a sensitive method for measuring the refractive index and thickness of thin films.

Planar Waveguide Theory: A planar waveguide consists of a thin film with refractive index nf sandwiched between a substrate (ns) and a cladding medium (typically air). Light can propagate as guided modes in the film when the effective index satisfies: ns < β/k0 < nf, where β is the propagation constant and k0 is the free-space wave number. Each guided mode corresponds to a specific combination of film thickness and refractive index.

Physical Principle: When light is coupled into a thin film waveguide through a prism, only specific angles (mode angles) allow efficient coupling due to phase matching conditions. These angles depend on the film's refractive index, thickness, and the surrounding media.

Mathematical Method: The algorithm uses a least-squares approach to fit the experimental mode angles to theoretical predictions. It creates a 2D parameter space (refractive index vs. thickness) and finds the combination that best matches all measured angles simultaneously. The parameter S represents the sum of squared errors between theoretical and experimental mode angles for each (nf, df) combination. The optimal solution corresponds to the minimum S value, or equivalently, the maximum 1/S value displayed in the results.

Example Data Validation: The default parameter values provided in this tool are based on experimental data for sapphire films from the reference: Ulrich, R. and Torge, R., "Measurement of thin film parameters with a prism coupler," Applied Optics 12, 2901-2908 (1973). The calculation results from this tool reproduce the published values, validating the accuracy of the implemented algorithm.
